Import Kintone records.csv + Attachments

Import clients, commercial accounts, addresses, notes, and attachments directly from your Kintone backup. Attachment files are processed directly from the server disk, allowing multi-gigabyte folders (e.g. 5.21 GB) to merge seamlessly without browser timeouts, payload limits, or rate limiting.

Deduplication & Validation Rules
  • Personal clients are matched by Driver License (licenseper) or Full Name. Existing clients are updated (blanks filled), never duplicated.
  • Commercial clients are matched by EIN (licensecom) or Business Name (business).
  • Subtable / Multiple Rows: Multiple rows for the same record (e.g. subtable rows) are safely grouped into a single client profile.
  • Document Deduplication: Attachment files are uploaded once; repeated imports automatically skip existing documents by filename.
  • Zero HTTP Timeout: Point directly to the server folder (e.g. C:\KintoneBackup\Attachments) to bypass browser uploads entirely.
