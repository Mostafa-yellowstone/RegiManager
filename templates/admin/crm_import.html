▶ Supported Columns & Format Information

Accepted Column Headers

The importer automatically maps headers case-insensitively, ignoring spaces and underscores. For example, First Name, first_name, or Client First Name are all mapped to the client's first name.

Client Fields:
  • first_name (Required)
  • last_name (Required)
  • middle_name
  • email
  • phone_number
  • dob (YYYY-MM-DD or date cell)
  • driver_license / dl
  • ssn
  • street_address / city / state / zip_code
Vehicle Fields (Optional):
  • vin (Required for vehicle import, 17-char)
  • make / model / year
  • color / plate_number
  • vehicle_type (passenger/truck/motorcycle/bus/trailer)
  • fuel_type (gas/diesel/electric/hybrid/natural_gas)
  • insurance_company / insurance_policy_number
  • registration_expiration_date

Notes:

  • If a client with the same name and email/phone/driver's license already exists in the selected Organization, the importer will update their details instead of creating a duplicate.
  • If a vehicle with the matching VIN already exists, it will be updated and linked to the owner.
  • All successfully imported vehicles will automatically trigger the system's registration expiration email alert checks.
